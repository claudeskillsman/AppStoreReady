# Security policy

AppStoreReady is meant to be safe to run on projects you don't fully trust. It reads files only, never runs project code or scripts, never uses the network, and never prints secret values.

## Reporting a vulnerability

If you find a way to make AppStoreReady execute code, access the network, write into the scanned project, or reveal a secret value in its output, please report it privately through GitHub: **Security › Report a vulnerability** on this repository.

Please include the AppStoreReady version, the command you ran, and a minimal project that reproduces the problem. Don't include real credentials.

## Supported versions

Only the latest release receives security fixes.
